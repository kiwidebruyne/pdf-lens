# PDF Lens

PDF Lens는 영어 연구 논문이나 교재의 선택한 부분을 오프라인 HTML 리더로 만드는 Codex 스킬입니다. 원본 PDF 페이지를 그대로 보여 주고, 한국어 직역·의역, 문맥에 맞는 단어 설명, 수식 확대 이미지를 제공합니다.

먼저 Codex 데스크톱 앱이 설치되어 있고 로그인되어 있어야 합니다. GitHub 계정은 필요하지 않습니다.

## Codex에 설치하기

직접 터미널을 열거나 개발 도구를 설치할 필요가 없습니다. 아래 문장을 복사해 Codex에 붙여 넣으세요.

```text
PDF Lens를 설치해 줘. 공식 안내는 https://raw.githubusercontent.com/kiwidebruyne/pdf-lens/main/docs/installation.md 에 있어. 이 컴퓨터에 설치하고 정상 설치를 확인한 뒤, PDF를 첨부해 사용할 수 있다고 알려 줘.
```

Codex가 설치를 진행합니다. 처음 설치할 때는 PDF Lens와 전용 PDF·브라우저 도구를 내려받기 위해 인터넷 연결이 필요합니다. Python이나 Node.js를 직접 설치할 필요는 없습니다.

## 사용하기

설치 후 영어 논문 PDF를 첨부하고 아래처럼 요청하세요.

```text
첨부한 영어 논문 전체를 PDF Lens 리더로 만들어 줘.
```

교재라면 원하는 인쇄 페이지, 장 또는 절을 말해 주세요.

```text
첨부한 교재의 인쇄 페이지 120–135를 PDF Lens 리더로 만들어 줘. 135쪽에서 예제가 끝나지 않으면 예제가 끝나는 쪽까지 포함해 줘.
```

Codex가 범위 전체를 미리 가공한 다음 HTML 파일을 제공합니다. 파일을 더블 클릭해 브라우저에서 열면 됩니다. 완성된 HTML을 읽는 데는 Codex·Python·인터넷이 필요 없습니다.

PDF Lens는 텍스트를 추출할 수 있는 PDF를 지원합니다. 스캔 이미지뿐이라 텍스트를 읽을 수 없는 PDF는 지원하지 않습니다. 번역을 고치고 싶으면 Codex에 해당 부분을 수정해 달라고 요청하세요.

새 PDF를 시작할 때 최신 정식 릴리스를 자동 확인합니다. 진행 중인 작업은 시작할 때의 버전으로 계속합니다. 직접 업데이트하거나 제거하려면 Codex에 요청하세요.

```text
PDF Lens를 최신 안정판으로 업데이트해 줘.
```

```text
PDF Lens 스킬과 전용 도구를 제거해 줘. 내가 만든 작업 파일과 HTML 리더는 남겨 줘.
```

설치 방법은 [설치 안내](docs/installation.md), 확인된 플랫폼과 릴리스 결과는 [검증 현황](docs/verification.md)을 참고하세요.
