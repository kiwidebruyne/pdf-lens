# PDF Lens

영어 논문·교재를 **원본 페이지 그대로 보면서 한국어로 정독하는 리더**로 만드는 Codex 스킬입니다. 문장을 누르면 한국어 번역이, 번역 창의 영어 단어를 누르면 기본 뜻과 문맥 뜻이 나타납니다. 수식은 원본에서 잘라낸 이미지로 보여 줍니다.

코딩을 몰라도 사용할 수 있습니다. GitHub 계정, 터미널 명령 입력, Python·Node.js 직접 설치는 필요하지 않습니다. **Codex 데스크톱 앱에 로그인하고 아래 문장을 보내면 됩니다.**

## 1. Codex 준비하기

1. [OpenAI의 데스크톱 앱 안내](https://developers.openai.com/codex/app/)에서 앱을 설치하고 로그인합니다. 앱 이름과 화면 구성은 버전에 따라 다를 수 있습니다.
2. 내 컴퓨터의 파일을 다룰 수 있는 Codex 작업을 엽니다. 웹 채팅에 설치 문장을 보내는 것만으로 내 컴퓨터에 설치되지는 않습니다.
3. 작업 폴더를 고르라고 하면 PDF와 결과를 보관할 폴더를 선택합니다. 코드 저장소는 필요하지 않습니다. 처음에는 `PDF 읽기` 같은 새 폴더면 충분합니다.

PDF Lens 자체에는 별도 번역 API 키를 넣지 않습니다. Codex 이용에는 계정의 이용 조건과 사용량 한도가 적용됩니다.

## 2. 이 문장을 복사해 설치하기

아래 상자 안의 문장을 전부 복사해 Codex 입력창에 붙여 넣고 보냅니다.

```text
PDF Lens를 설치해 줘. 공식 안내는 https://raw.githubusercontent.com/kiwidebruyne/pdf-lens/main/docs/installation.md 에 있어. 최신 공개 안정판의 ZIP과 체크섬을 확인해서 이 컴퓨터에 설치해 줘. 정상 설치를 확인한 뒤 설치된 버전과 다음 사용 방법을 알려 줘. 내가 터미널 명령을 직접 입력하지 않도록 처리해 줘.
```

Codex가 도구를 내려받고 설치합니다. **첫 설치에는 인터넷이 필요합니다.** 완료 메시지에 설치된 버전과 정상 설치 확인이 있어야 합니다. 실패했다면 같은 대화에서 “오류를 확인해서 설치를 마쳐 줘”라고 요청하세요. 설명만 왔다면 “이 컴퓨터에 실제로 설치하고 확인해 줘”라고 보내세요.

## 3. PDF를 첨부하고 읽을 범위 말하기

처음에는 영어 텍스트 PDF의 **2–5쪽**으로 시작하세요. 일반 PDF 뷰어에서 본문 글자를 드래그해 선택·복사할 수 있는지 확인하면 도움이 됩니다. 사진으로 스캔한 PDF의 OCR은 지원하지 않습니다.

Codex 대화에 PDF 파일을 첨부합니다. 첨부할 수 없다면 선택한 작업 폴더에 PDF를 넣고 파일 이름을 말해 주세요. 다음 중 하나를 보냅니다.

```text
첨부한 영어 논문을 PDF Lens로 작업해줘.
```

```text
첨부한 교재의 120–124페이지를 PDF Lens로 작업해줘.
```

## 4. 리더에서 읽기

원문 페이지가 먼저 열립니다. 처음에 번역이 없는 것은 정상입니다. Codex가 확인한 문장부터 결과를 반영하며, 작업 중에는 Codex 작업을 계속 실행해 두세요.

| 하고 싶은 일 | 조작 |
| --- | --- |
| 문장 번역 읽기 | 원문 문장을 클릭하거나 읽을 부분을 드래그합니다. 준비된 문장의 영어 원문과 한국어 번역이 뜹니다. 일부만 선택해도 해당 문장 전체로 맞춰질 수 있습니다. |
| 단어 뜻 보기 | 열린 번역 창 안의 클릭 가능한 영어 단어를 누릅니다. `기본 뜻`과 이 문장에서의 `문맥 뜻`을 비교합니다. |
| 수식 읽기 | 수식이 포함된 부분을 선택하면 창에서 원본 수식의 확대 이미지를 봅니다. |
| 작은 글자 읽기·쪽 이동 | 위쪽의 확대·너비 맞춤·쪽수·목차 기능을 이용합니다. |
| 아직 준비되지 않은 부분 보기 | `번역 준비 중입니다`가 뜨면 기다립니다. 결과가 반영되면 열린 창도 갱신됩니다. |

단어를 누를 때마다 AI에 새 질문을 보내는 방식이 아닙니다. 미리 작성된 결과를 보여 줍니다. 번역·단어 뜻은 AI가 작성하므로 중요한 내용은 원문과 함께 확인하세요. 수식 이미지는 풀이를 추가하는 기능이 아닙니다.

## 5. 완성 파일 저장하기

전체 작업과 검사가 끝나면 **최종 HTML**이 생성됩니다. 실시간 리더의 최종 파일 링크나 Codex가 알려 준 경로에서 `reader.html`을 저장하세요. 원문만 보이거나 일부 번역만 나온 화면은 아직 완성본이 아닙니다.

완성된 HTML은 파일을 더블 클릭해 브라우저로 열 수 있습니다. **완성본을 읽을 때는 Codex·Python·인터넷이 필요 없습니다.** 수정하거나 작업을 이어가려면 원본 PDF와 작업 폴더도 보관하세요. 기본 결과 위치는 선택한 작업 폴더의 `output/pdf-lens/` 아래입니다.

## 다시 열기·수정하기

같은 Codex 대화에서 다음처럼 요청하세요. 새 대화라면 원본 PDF와 작업 폴더 위치도 알려 주세요.

```text
아까 만들던 PDF Lens 리더를 같은 작업 폴더에서 다시 열고 이어서 작업해 줘.
```

```text
인쇄 122쪽의 “원문 문장 일부” 번역과 단어 뜻을 확인해 줘. 여기서는 X라는 의미 같아. 원문을 확인해 수정하고, 최종 HTML에도 반영해 줘.
```

연결이 끊기면 이미 반영된 부분은 계속 읽을 수 있지만 새 결과는 들어오지 않습니다. Codex에 같은 작업을 다시 열어 달라고 요청하세요. 스킬을 업데이트해도 진행 중인 작업은 시작할 때의 버전으로 이어집니다.

## 파일과 개인정보

실시간 리더는 내 컴퓨터의 로컬 서버에서 열리고, 완성된 HTML은 오프라인으로 읽습니다. **하지만 번역·단어 뜻을 만드는 동안 Codex가 PDF에서 읽은 텍스트나 페이지 이미지는 모델 처리 과정에서 클라우드로 전달될 수 있습니다.** “완성본이 오프라인”이라는 말이 제작까지 모두 기기 안에서 처리된다는 뜻은 아닙니다. 민감한 자료는 계정·조직의 데이터 정책을 확인한 뒤 사용하세요.

이 저장소는 스킬과 직접 만든 시험 자료를 배포합니다. 사용자가 첨부한 타인의 논문·교재나 그 내용이 들어간 HTML을 자동으로 공개하지 않습니다. 결과 HTML에도 원문 내용이 들어가므로 다른 사람에게 공유하려면 원문과 번역의 공유 권한을 확인하세요.

## 업데이트·제거·지원 범위

```text
PDF Lens를 최신 안정판으로 업데이트하고 설치된 버전을 확인해 줘.
```

```text
PDF Lens 스킬과 전용 도구를 제거해 줘. 내가 만든 작업 파일과 HTML 리더는 남겨 줘.
```

새 PDF 작업을 시작할 때 최신 안정판을 자동 확인합니다. 업데이트가 실패하면 가능한 경우 기존 설치로 계속하며, 더 높은 로컬 버전을 이전 공개 버전으로 되돌리지 않습니다.

설치 경로는 macOS와 Windows용입니다. v0.3 실시간·오프라인 리더는 로컬 macOS ARM64와 GitHub의 macOS ARM64·Windows Server 2025 x64 환경에서 Chromium으로 확인했습니다. 개인 Windows 10/11 PC와 Safari·Firefox는 아직 직접 시험하지 않았습니다. 자세한 확인 환경과 제한은 [검증 현황](docs/verification.md), Codex가 수행할 설치 절차는 [설치 안내](docs/installation.md)를 참고하세요.
